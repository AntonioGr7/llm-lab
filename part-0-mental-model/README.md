# Part 0 — Mental Model

Before any code, you need a picture of the whole thing.

Most LLM courses dive into attention on page one. That's like teaching someone to drive by starting with the carburetor. You learn what the carburetor does, but you don't yet know what driving *is*. By the time you assemble the car, you've forgotten why you wanted one.

This Part is the map. Two modules, both short, both important.

## Modules

- **[00 — What We're Actually Building](00-what-we-are-building/)** — The full pretraining → post-training → deployment pipeline as one picture. What each stage costs, what each stage buys you. How to read this course.
- **[01 — Tools and Environment Setup](01-tools-and-environment/)** — RunPod / Lambda Labs, local dev workflow, W&B, HuggingFace. The "develop offline, run online" pattern that makes the $50 budget possible.

## What you'll be able to do at the end of this Part

- Explain the full pipeline of training a modern LLM to someone who's never seen one.
- Set up a development environment where iteration is cheap and execution is fast.
- Know which experiments in the rest of this course you'll actually run and which you'll read.

## Time and cost

- Reading time: ~30 minutes.
- Compute cost: $0. Everything here runs locally.
